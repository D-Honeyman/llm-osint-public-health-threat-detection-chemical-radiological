# LLM Evaluation for Detection of Chemical and Radiological Public Health Events

Dataset and evaluation code for benchmarking a large language model for detecting
chemical and radiological public health threats from open-source intelligence (OSINT)
news articles.

This repository accompanies the manuscript Chemical and Radiation Threat Detection
Using a Large Language Model (under review, International Journal of Data Science
and Analytics).

The aim is to enable reproducibility of the evaluation framework and to provide a
benchmark dataset for future research in event-based public health surveillance using
large language models.


## Overview

Large language models are increasingly used for automated detection of emerging public
health threats from open-source intelligence such as news media. Reproducible evaluation
frameworks for assessing their ability to extract structured information from these
sources remain limited.

This repository provides:


A gold-standard annotated dataset of 200 news articles
Human annotations and LLM extraction outputs (in the same file)
The evaluation pipeline used to compute precision, recall and F1 scores

##Dataset

The evaluation dataset contains 200 news articles, each manually annotated by human
reviewers. Each row is a single article.

Annotations follow a structured bullet-list format representing the entities extracted
from each article.


## Entities evaluated

**Threat entities**


Event identification
Chemical substance
Radiological substance
Fatality count
Case number


**Location entities**


Country
State
County
City


**Temporal entities**


Timeframe
Years, months, dates, days of the week


Two reporting transformations are applied in the evaluation script: LOCATION is
reported as COUNTRY, and Answer is reported as Event identification. These
standardise reporting terminology and do not alter the underlying annotations.


## Evaluation method

The script computes entity-level precision, recall and F1, with 95 per cent
Clopper-Pearson confidence intervals.

The pipeline performs:


1. Parsing of structured entity annotations
2. Label normalisation
3. Entity matching, combining exact string matching with semantic similarity from
    sentence embeddings, resolved via optimal (Hungarian) assignment
4. Calculation of evaluation metrics


Embedding-based matching uses sentence-transformers/all-MiniLM-L6-v2.


## Installation

bashgit clone https://github.com/D-Honeyman/llm-osint-public-health-threat-detection-chemical-radiological.git
cd llm-osint-public-health-threat-detection-chemical-radiological
pip install -r requirements.txt

Python 3.9 or later is recommended.


## Running the evaluation

bashpython evaluator.py

This uses the bundled dataset and writes evaluation_results.csv containing
entity-level metrics.

To specify paths or a different embedding model:

bashpython evaluator.py \
  --input evaluation_dataset_200_articles.xlsx \
  --output evaluation_results.csv \
  --embedding_model sentence-transformers/all-MiniLM-L6-v2


## Reproducibility

The proprietary components used to collect and process the original news data,
including the news API ingestion pipeline and large-scale scraping infrastructure,
are not included here due to institutional and contractual restrictions.

The components required to reproduce the reported evaluation results are provided:
the LLM inference outputs, the human gold-standard annotations, and the evaluation code.
